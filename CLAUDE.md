## Project Overview

This is a Next.js 16 corporate website for 联合化工 (Unice Chemical), built with React 19, TypeScript, and Tailwind CSS. The project features a modern Apple-style design with a golden yellow theme color scheme and uses PostgreSQL with Prisma ORM for data management.

## Development Commands

### Basic Development
```bash
npm run dev          # Start development server (localhost:3000)
npm run build        # Build production version
npm run start        # Start production server
npm run lint         # Run ESLint
```

### Database Operations
```bash
npx prisma generate  # Generate Prisma client
npx prisma migrate dev    # Run database migrations
npx prisma studio    # Open Prisma Studio browser
npx prisma db seed   # Seed database with initial data
```

### Docker Development
```bash
docker-compose up -d    # Start all services (database + app)
docker-compose down      # Stop all services
```

## Architecture

### Project Structure
```
app/
├── layout.tsx          # Root layout with navigation and footer
├── page.tsx            # Homepage
├── globals.scss        # Global styles and CSS variables
├── components/         # Reusable UI components
│   └── navigation.tsx  # Main navigation component
├── lib/               # Utilities and configurations
│   └── prisma.ts      # Prisma client instance
├── products/          # Product pages (list and detail)
├── about/             # Company information pages
├── news/              # News and updates pages
├── careers/           # Recruitment pages
├── contact/           # Contact form and information
└── api/               # API routes for backend functionality
```

### Database Schema
The application uses PostgreSQL with the following main models:
- `Product` - Chemical products with CAS numbers, categories, and detailed specifications
- `Category` - Product categorization with hierarchical support
- `News` - Company news and announcements
- `Career` - Job postings and recruitment information
- `User` - Admin user management
- `ContactSubmission` - Contact form submissions
- `HeroBanner` - Homepage banner management

### Design System
- **Primary Colors**: Golden yellow theme (`#d4af37`) with Apple-style aesthetics
- **Typography**: Inter font family with system fallbacks
- **CSS Variables**: All colors defined as CSS custom properties for easy theming
- **Animations**: Custom animations for fade-in, float, and scale effects
- **Responsive**: Mobile-first design using Tailwind CSS breakpoints

## Development Guidelines

### Component Development
- Use TypeScript with proper type definitions
- Follow Apple-style design patterns (minimal, clean, premium)
- Implement responsive design using Tailwind classes
- Use semantic HTML elements

### Database Operations
- Use Prisma client from `app/lib/prisma.ts`
- Implement proper error handling for database operations
- Use TypeScript types generated by Prisma for type safety

### Styling Approach
- Prefer Tailwind CSS classes over custom SCSS
- Use CSS variables for theme colors defined in `globals.scss`
- Implement hover states and transitions for interactive elements
- Follow the golden yellow color scheme for brand consistency

### Code Organization
- Place reusable components in `app/components/`
- Use API routes in `app/api/` for backend functionality
- Follow Next.js 13+ app router conventions
- Implement proper SEO metadata in page components
