# 官网绝对化用语整改记录

- 日期：2026-08-16
- 涉及站点：www.uniche.cn（江西联合化工 / Unice Chemical）
- 状态：代码与 seed 已完成整改并提交；线上数据库整改详见下文

---

## 1. 投诉概要

针对官网宣传文案的举报指出：网站使用「一流」等表述（如"采用一流的研发和生产设备，拥有一流的研发团队""生产一流产品、提供一流服务""一流生产和检测设备"），连续出现 5 次以上，并与「顶级」「最佳」含义相同，属于《广告法》第九条明令禁止的绝对化用语；同时援引《反不正当竞争法》第八条，主张构成虚假宣传，应依《广告法》第五十七条、《反不正当竞争法》第二十条处罚。

## 2. 法律依据（整改所依据/回应的规范）

- 《中华人民共和国广告法》第九条第（三）项：广告不得使用"国家级"、"最高级"、"最佳"等用语（含与其含义相同的绝对化用语，如"一流""顶级""全球领先"等）。
- 《中华人民共和国反不正当竞争法》第八条第一款：经营者不得对其商品作虚假或者引人误解的商业宣传。
- 广告法第五十七条、反不正当竞争法第二十条为罚则条款（本次以主动整改、消除风险为目标）。

## 3. 排查范围

官网内容已后台化，线上展示文案主要来自 **Payload CMS + PostgreSQL 数据库**（由 seed 灌入）；`app/lib/globals.ts` 中的兜底常量仅在数据库字段缺失/读取失败时使用。因此同时整改三处：

| 来源 | 说明 |
|---|---|
| `app/lib/globals.ts` | 代码兜底：首页/关于/联系页 `FALLBACK_*` 常量 |
| `payload/seed.ts` | 数据库种子源（重建数据时灌入） |
| 线上 Payload/PostgreSQL 数据库 | Globals（home-page / about-page 等）+ 集合（hero-banners / news / products / careers） |

排查到的绝对化用语：`一流`（6 处）、`最先进`、`世界一流`、`全球领先`、`顶尖`、`国际领先水平`、`世界先进水平`、以及边缘用语 `引领行业…`（如"引领行业未来""引领行业技术发展方向"）等。

> 注：含「一流」的"关于我们"简介段落仅存在于代码兜底 `FALLBACK_ABOUT_PAGE`；当前线上库 introContent 仅两个段落（seed 灌入），不含该段，但兜底一并修正，保证任何兜底场景均合规。

## 7. 后台文案撰写规范（供后续运营）

后续在 Payload 后台新增/编辑文案时，禁止使用以下绝对化用语（非穷尽）：

`最高、最高级、最佳、最优、最好、最大、最强、最先进、一流、世界一流、顶级、顶尖、至尊、极致、巅峰、第一、No.1、唯一、独家、首选、国家级、世界领先、国际领先、全球领先、行业领先、领先地位、领导品牌、领导者、绝对、独一无二、无与伦比、遥遥领先等`

**替代建议**：
- 用可核实的事实与数据说话（认证、专利数、标准、服务年限等）。
- 「领先/引领」类表述改为「推动、促进、深耕、专注于、致力于」。
- 「最/顶级」类表述改为「先进、专业、可靠、高品质、高标准」或删除。
- 政府授予的资质名称（如"国家级新型工业化产业示范基地"）属于事实陈述，可保留，但不得用于为自身商品背书性绝对化宣传。
